# Writing Readable Text

Make text easy to understand on the first pass and compare across items.
Use predictable structure so variation communicates meaning.

## Scope

- Apply the full checklist to related items in feeds, dashboards, tables, headlines, notifications, and lists.
- For standard prose, use sentence clarity and important-word placement without forcing a repeated template.
- Preserve the requested voice, format, facts, names, numbers, uncertainty, and material qualifications.

## Workflow

1. Identify the reader, purpose, and comparison unit.
2. Choose a shared sentence pattern, vocabulary, tense policy, and field order.
3. Draft related items together using the checklist below.
4. Compare items side by side. Read their first two words. Revise differences that do not reflect meaning.
5. Return the requested text. Explain revisions only when asked.

Ask for missing context only when it would materially change the result.

## Five Point Checklist

 Check   | Apply
---------|---
 Sentence order | Put the subject before its action. Use verb-first wording when a shared subject is unambiguous.
 Important words first | Move distinguishing words early. Remove repeated introductory filler.
 Structure and vocabulary | Use one sentence pattern and field order for comparable items, and one term per concept.
 Meaningful variation | Match detail depth. Use consistent fields so differences in length or emphasis reflect evidence.
 Purpose-aligned verbs | Use `praise`, `complain`, `request`, or `report` according to the source sentiment and text objective.

Verb guide: `praise` for positive feedback, `complain` for negative concern, `request` for asks for change, and `report` for factual updates.

## Example

Before: "There were some issues with the billing page, and the customer said they were upset and asked for a fix."

After: "Customer complained about the billing page and requested a fix."

This shows the checklist in action: the subject comes first, the distinguishing words stay early, the sentence pattern is consistent, and the verb matches the source sentiment without adding unsupported detail.

## Application Rules

- Use past tense for completed work, continuous for active work, future for planned work, and imperative for commands.
- Keep tense consistent within each state. Preserve state differences across mixed lists.
- Keep a shared subject brief. Place the distinguishing verb or object immediately after it.
- Place comparable counts, dates, and versions in consistent fields when the format permits.
- Preserve mixed sentiment. Keep each qualification with its claim, and leave unconfirmed causes unconfirmed.
- Mark missing required evidence as unavailable. Omit unsupported optional fields consistently. Never invent examples to fill a template.

## Common Mistakes

Avoid synonym rotation, invented examples, forced equal lengths, softened complaints, deleted qualifications, and flattened differences that are actually meaningful.
